# Arcis Instagram・DMからの移行計画 第1版

作成日：2026年9月28日
状態：**案**。方式（A案・B案）は、この資料で移行手順と管理の手間を比べてから決めます。

---

## 0. 前提（現在の運営）

- Arcisは開業済みです。今回は、**既存のクラスとヨガパンツの申し込み方法・支払い方法を変える**ためのサイト制作です。
- 現在は、クラスもヨガパンツもInstagramに掲載し、**DMで申し込み・購入のやり取り**をしています。
- 公式LINE：https://line.me/R/ti/p/@317tvtys
- 月会員制度と、前払いポイント（購入日から3か月有効）を導入したい意向があります。

## 1. 移行の考え方

1. **一度に全部を切り替えない**。まず「体験・1回参加の予約」と「ヨガパンツの購入」をSquareに移します。月会員とポイントは、仕組みが決まってから移します。
2. **並行期間を設ける**。サイト公開後もしばらくはDMを受け付け、DMには予約ページのリンクを返します。
3. **切り替える前に、既存の予約をSquareに登録する**。DMで受けた予約をSquareに入れておかないと、オンライン予約と合わせて定員を超えるおそれがあります。
4. **ネットが苦手なお客様の窓口を残す**。公式LINEで相談を受け、スタッフが代わりに予約を登録します。

## 2. 移行の手順（A案で始める場合）

### 第1段階：準備（公開の2〜4週間前）

| 作業 | 内容 | 担当 |
|---|---|---|
| Squareアカウント作成・審査 | 本人確認、入金口座、2段階認証 | 運営者 |
| クラスの登録 | 体験レッスン・通常レッスンを「クラス」として登録し、定員・料金・キャンセル期限を設定 | 運営者（制作側が手順書を用意） |
| ヨガパンツの登録 | サイズ・色ごとの在庫数を**実際に数えて**登録。送料と発送方法も設定 | 運営者 |
| 既存のお客様の整理 | DMでやり取りしている方のうち、今後も連絡が必要な方（予約中・会員・注文中）を一覧にする | 運営者 |
| 既存の予約の登録 | DMで受けている**今後の予約を、Square予約に手動で登録**（前払い済み・当日払いの区別も記録） | 運営者 |
| 未発送の注文 | DMで受けたヨガパンツの未発送分は、**これまでの方法で最後まで対応**（Squareには入れない） | 運営者 |
| サイトの公開準備 | 規約・特定商取引法の表記・プライバシーポリシー・キャンセル規定を掲載 | 制作＋運営者 |
| テスト | 少額で予約・購入・キャンセル・返金を試す | 制作＋運営者 |

### 第2段階：お知らせと並行期間（公開日から2〜4週間）

| 作業 | 内容 |
|---|---|
| サイト公開 | トップに「お申し込み方法が変わります」のお知らせを表示 |
| Instagram | プロフィールのリンクをサイトに変更。お知らせの投稿を固定し、ハイライトに「予約方法」をまとめる |
| 公式LINE | 登録者に一斉にお知らせ。メニューに「予約する」「商品を見る」「相談する」を置く（LINE公式アカウントの機能は管理画面で確認） |
| DMへの返信 | 新しいDMには、予約ページのリンクと「操作がわからなければLINEで相談」を返す（決まった文面を用意） |
| 使い方の案内 | スマホ画面の手順を画像1〜3枚にまとめ、Instagram・LINEで配布 |

### 第3段階：切替日以降

- 新しい予約・購入は、**サイト（Square）からだけ受け付けます**。
- DMでの申し込みには、予約ページのリンクを返します。LINEでの相談は続けます。
- 月会員の方は、方式が決まるまで**LINEで希望日を受け付け、スタッフがSquare予約に登録**します（第4章）。

### 第4段階：月会員・ポイントの移行（方式決定後）

- B案またはC案の仕組みが決まってから行います。
- 月会員の月謝を自動課金に切り替える場合は、**すでに支払い済みの月と重ならない請求開始日**を会員ごとに決めます。
- 既存の前払い（回数券など）の残りがある場合は、残りを新しい仕組みに移す方法を別に決めます。

## 4. A案とB案の比較（移行と管理の手間）

| 比べる点 | A案：Square＋手作業 | B案：Square＋外部サービス（例：KINCHAKU） |
|---|---|---|
| 体験・1回参加 | Square予約（オンラインで完結） | 外部サービスまたはSquare予約 |
| ヨガパンツ | Squareのオンラインショップ | 同左 |
| 月会員の予約 | LINEで受けてスタッフが登録（**今のDMに近い**） | 会員が自分で予約（**会員の登録作業が必要**） |
| 月会員の回数管理 | 手作業（一覧表など） | 自動（検証で確認が必要） |
| ポイント | **販売しない**（手作業での残高・期限管理は、誤りや不公平が起きやすいため） | 要件を満たせば販売できる（検証で確認が必要） |
| お客様の移行の負担 | 小さい（会員は今までどおりLINE） | 中（会員ごとに登録・カード登録） |
| 運営者の移行作業 | 小さい | 中（会員データの登録・プラン設定） |
| 移行後の日々の手間 | 会員が多いほど増える | 少ない |
| 月額費用 | Square予約プラス 3,000円 | 左に加えて外部サービスの月額（**料金は未確認**） |

**進め方の案**
1. **A案で切り替えを始めます**（体験・1回参加・ヨガパンツをSquareへ）。お客様の変化が小さく、すぐに始められます。
2. 並行して、**B案の無料体験で、ポイントの要件を検証**します（[membership-points-proposal.md](membership-points-proposal.md) の3-2）。
3. 検証の結果をもとに、月会員・ポイントの仕組み（B案またはC案）を決め、第4段階へ進みます。

## 5. 移行のためにご準備いただくもの

- 現在の**月会員の人数**、月謝の支払い方法（振込・現金など）と支払日
- **すでに受けている予約**の一覧（日時・お名前・支払い済みかどうか）
- **前払いの残り**（回数券など）がある方の一覧
- ヨガパンツの**サイズ・色ごとの在庫数**、価格、送料、発送方法、返品条件、実物写真
- 1回参加（ドロップイン）の料金（リーフレットに記載がないため）
- 切替日の候補

## 6. 次に決めること（優先順）

### 最優先（切り替えの準備を始めるために必要）
1. **移行の始め方**：A案で始め、並行してB案を検証する進め方でよいか
2. **既存の月会員の状況**：人数、月謝の支払い方法（振込・現金など）と支払日、前払いの残り（回数券など）の有無
3. **既存の予約**：DMで受けている今後の予約を、いつSquareに登録するか（切替日の前に全件登録が必要）
4. **切替日とDM受付の終了日**：並行期間（2〜4週間）をどう取るか
5. **キャンセル規定**：期限後から前日中までの扱い（おすすめ：期限を過ぎたら全額負担で一本化）

### 高（サイト公開までに必要）
6. **ヨガパンツの販売情報**：サイズ・色・税込価格・在庫数・送料・発送方法・返品条件と、実物の写真
7. **1回参加（ドロップイン）の料金**と、体験レッスンをオンライン予約だけにするか（リーフレットではLINE・InstagramのDM）
8. **ヘッダーのロゴ**：見本の切り替えで「文字のみ」「マーク付き」を比べて選ぶ
9. **InstagramのURL**（@arcis.yoga）の確認
10. **Squareのアカウント作成**：本人確認・入金口座・2段階認証

### 中（月会員・ポイントを始めるまでに必要）
11. 月会員を自動課金にするか、毎月の請求にするか。使わなかった回数の繰り越し
12. ポイントの値段・販売単位・レッスンごとの消費ポイント数・使えるレッスン
13. ポイントの期限の数え方（おすすめ：3か月後の同じ日の前日まで）と、教室都合で返したポイントの延長
14. 家族のシェア会員・ポイント共有の扱い
15. B案の検証結果を受けて、B案かC案かを決める

### 低（後からでも調整可能）
16. 画像の差し替え（[image-list.md](image-list.md)）とロゴの作り直しの有無
17. 独自ドメイン
18. アーカイブ動画の配信方法
