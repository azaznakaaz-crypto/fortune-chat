## 前提

- 掲載する写真は、すべて**イメージ画像**として扱います（実際の教室・講師の写真として紹介しません）。サイト上では各写真に「イメージ」と表示し、必要な箇所に「写真はイメージです」と添えます。
- 現在の画像は、リーフレット（画像生成で作成）から切り出したものです。リーフレット1枚の大きさが約1,050×1,490pxのため、切り出した写真は小さく、**パソコンや高精細なスマートフォンでは粗く見えます**。
- 推奨サイズは、表示サイズの約2倍です（高精細な画面でもにじまないようにするため）。サイトに載せる際に、軽い形式（WebP）へ変換し、画面幅に合わせた大きさで配信します。

## 4. 画像生成で作り直す場合の注意

- **同じ雰囲気**で作り直す場合は、上の表の推奨サイズ以上（例：1536×1024や1024×1536など、生成できる最大の大きさ）で作成してください。
- 自然光・アイボリーからベージュの色味・木の温もり・草花・クリスタルボウルの透明感を共通の条件にすると、ページ全体がそろいます。
- 人物が写る画像（ヨガ・ヨガニードラ）は、実在の講師や生徒と誤解されないよう、「イメージ」の表示を続けます。
- 画像の中に文字やQRコードを入れないでください（サイトでは文字をページ側で表示します）。
