## 0. 最初に：安全のための約束

- **パスワード・2段階認証のコード・アクセストークン・APIキーは、チャットやメールに貼らないでください。** 制作側がそれらを求めることはありません。
- 制作側にお送りいただくのは、**お客様に公開するためのURLだけ**です（予約ページ・ショップ・商品ページのURL）。これらは誰が見てもよい情報です。
- 将来、在庫や日程をサイトに自動表示する段階になった場合も、秘密の鍵は**運営者の方がサイトの公開先の「秘密の設定」画面に直接入力**する方法をとります。チャットでは受け渡しません（第6章）。
- **お金がかかる操作**（有料プランの契約・実際の決済）は、手順の中で「💴」の印をつけ、金額と内容を先に書いています。印のある手順は、内容をご確認のうえ、実行するかどうかを決めてください。

**画面名について**：画面名は、Squareの確認できた日本語ヘルプ・コミュニティの記載に基づいています。Squareの更新で名前や場所が変わる場合があります。見つからない場合は、Squareのヘルプセンターで記事名を検索するか、Squareのサポートにお問い合わせください。

## 1. 現在のサイト構成で連携できる範囲

| 内容 | 今のサイト構成（静的なページ）での連携 | 秘密の鍵 |
|---|---|---|
| 「空き状況を確認する」→ Square予約の予約ページ | **できる**（URLを設定するだけ） | 不要 |
| 「在庫を確認する」「オンラインショップを見る」→ Squareのショップ | **できる**（URLを設定するだけ） | 不要 |
| 支払い | **できる**（Squareの画面で行う。サイト側はカード情報を扱わない） | 不要 |
| サイト上に在庫数・残席・価格を自動表示 | **できない**（サーバー側の仕組みが必要） | 必要 |
| 月会員の予約・ポイントの残高管理 | **できない**（B案の外部サービスか、C案の専用の仕組みが必要） | 方式による |

**結論**：今の構成では、**予約・購入・支払いはSquareの画面へ移動して行う形**でつなげます。サイトのボタンは、SquareのURLを設定すると押せるようになり、設定するまでは「準備中」と表示されて押せません。

**月会員・ポイント制について**：今回の連携は第一段階です。月会員・ポイント制は引き続き導入する前提で、方式（B案の検証→B案またはC案）を決めてから進めます。手作業での管理で確定するものではありません。

## 2. 最初に行う設定（費用なし）

### 2-1. 2段階認証を設定する

1. パソコンのブラウザーで Square にログインし、**Square データ**（管理画面）を開きます。
2. **アカウントと設定** を開きます。
3. **サインインとセキュリティ**（または「セキュリティ」）の項目で、**2段階認証** をオンにします。
4. 認証の方法は、SMSよりも **認証アプリ**（Google Authenticator など）がより安全です。
5. 予備の電話番号も登録しておきます。

参考：[2段階認証（Squareヘルプ）](https://squareup.com/help/us/en/article/5593-2-step-verification)、[2段階認証でアカウントを保護する方法（Square）](https://squareup.com/jp/ja/campaign/two-step-verification)

### 2-2. 担当者を追加する場合（任意）

- ほかの方にも作業をお願いする場合は、ログイン情報を共有せず、**スタッフ（チームメンバー）として個別に招待**してください。
- 招待する画面と、権限を細かく分けられるかどうかは、ご契約のプランによって異なる可能性があります（未確認）。追加する前にお知らせください。費用がかかるかどうかを一緒に確認します。

### 2-3. 事業者情報を確認する

1. **アカウントと設定** →**ビジネス情報**（または「店舗情報」）を開きます。
2. 事業者名・連絡先メールアドレス（**arcis.yoga.1013@gmail.com**）・電話番号を確認します。
3. 住所欄には正式な住所を入力します。**サイトに番地まで載せるかどうかは別に決めます**（サイトには「熊本市南区良町」までを表示し、詳細はご予約時にお知らせする形にしています）。
4. **入金口座** が登録済みか確認します。

## 3. ヨガパンツの販売（費用：月額0円。売れたときに決済手数料3.6%）

### 3-1. 商品を登録する

1. Square データで **商品** →**商品ライブラリ** を開きます。
2. **商品を作成** を押します。
3. 商品名「ヨガパンツ」、説明、税込価格を入力します。
4. サイズ・色がある場合は **バリエーション** を追加します（例：S／M／L × 色）。
5. 各バリエーションの **在庫数** を入力します。**実際に数えた数**を入れてください。
6. 写真は、実物を撮影したものを登録します（イメージ画像は商品写真に使わない）。
7. 保存します。

参考：[商品と在庫管理（Squareヘルプ）](https://squareup.com/help/us/en/topic/items-and-inventory)

### 3-2. オンラインショップを作る（Square オンラインビジネス・無料プラン）

1. Square データで **オンライン**（または「オンラインビジネス」）を開きます。
2. サイトの作成を始め、**無料プラン**を選びます。💴 有料プランの案内が表示されても、選ばずに進めてください（有料プランは必要になった時点で、金額を確認してから検討します）。
3. ショップに「ヨガパンツ」を表示するよう設定します。
4. **お届け方法** →**発送** →**発送プロファイルを追加** で、送料を設定します（全国一律、都道府県別など）。
5. 返品条件と、特定商取引法に基づく表記に必要な情報を設定します。
6. ショップを **公開** します。
7. 公開したショップのURLと、ヨガパンツの商品ページのURLをコピーします。

参考：[送料プロフィールを設定する（Squareヘルプ）](https://squareup.com/help/us/en/article/8042-create-and-manage-shipping-rate-profiles)、[ECサイト向けサービス（Square）](https://squareup.com/jp/ja/ecommerce)

**別の方法（決済リンク）**：ショップを作らず、商品ごとの **決済リンク**（「商品を販売する」の種類。お届け先の住所を入力する形）を使う方法もあります。ただし、決済リンクで売ったときに在庫数が自動で減るかは確認できていません。**在庫の管理を確実にするため、ショップの利用をおすすめします。**
参考：[決済リンクを作成・共有する（Squareヘルプ）](https://squareup.com/help/us/en/article/6692-get-started-with-square-checkout-links)

## 4. レッスンの予約（Square 予約）

### 4-1. まず無料で準備する

1. Square データで **予約** を開きます（「支払い」→「予約」の場合もあります）。
2. 現在のプランが **フリー（0円）** であることを確認します。
3. 事業所の営業時間、キャンセルの受付方法を確認します。

### 4-2. 💴 グループレッスン（クラス）を使うための有料プラン

| 内容 | 金額 | 備考 |
|---|---|---|
| **Square 予約 プラス** | **月額3,000円（税込・1店舗あたり）** | 定員つきのクラス予約に必要 |
| 決済手数料 | オンライン決済ごとに3.6% | 例：体験1,000円なら36円 |

- 無料お試し期間の有無、日割りの有無、解約の条件は確認できていません。**契約画面で表示される金額・請求日・解約方法をご確認ください。**
- **この契約は、内容をご確認のうえで運営者の方が決めてください。** 契約してよい場合は、お知らせいただければ次の手順に進みます。

### 4-3. プラス契約後の設定

1. **予約** →**設定** で、**クラス** を作成します（体験レッスン・通常レッスン）。
2. 各クラスに **料金・定員・所要時間・講師** を入力し、開催日時を登録します。
3. **キャンセルポリシー** を設定します。決まった規定は次のとおりです。
   - 期限：クラス開始時刻の24時間前（例：10月10日10:00開始 → 10月9日10:00まで）
   - 期限までのキャンセル：全額返金
   - 期限後のキャンセル・無断欠席：返金なし
4. **Squareの設定で「期限後は返金しない」を自動で守れるかは確認できていません。** テストで確認し、自動で守れない場合は、期限後のオンラインでのキャンセルを受け付けない設定にし、LINEで連絡をもらう運用にします。
5. **DMで受けている今後の予約を、スタッフの操作でクラスに登録**します（オンライン予約を公開する前に全件）。
6. **オンライン予約** を有効にします。
7. **予約** →**オンライン予約** →**チャネル** →**URLを入手** で、予約ページのURLをコピーします。

参考：[オンライン予約の設定（Squareヘルプ・米国版）](https://squareup.com/help/us/en/article/5355-set-up-online-booking-with-square-appointments)、[クラス予約の告知（Square公式コミュニティ）](https://community.squareup.com/t5/Square%E3%83%97%E3%83%AD%E3%83%80%E3%82%AF%E3%83%88%E3%81%AE%E6%9C%80%E6%96%B0%E6%83%85%E5%A0%B1/Square-%E4%BA%88%E7%B4%84-%E3%82%AF%E3%83%A9%E3%82%B9%E4%BA%88%E7%B4%84%E3%81%A7-%E8%A4%87%E6%95%B0%E3%81%AE%E3%81%8A%E5%AE%A2%E3%81%95%E3%81%BE%E3%81%8C%E4%BA%88%E7%B4%84%E3%81%A7%E3%81%8D%E3%82%8B%E3%82%AF%E3%83%A9%E3%82%B9%E3%82%92%E4%BD%9C%E6%88%90/ba-p/662627)
