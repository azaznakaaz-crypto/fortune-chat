# 19_覚醒体験した人、ディセンション恐れすぎ問題 — Premiere 自動編集一式

カット済みのPremiereプロジェクト「覚醒体験した人、ディセンション恐れすぎ問題.prproj」に、編集設計書どおりの追加編集を行う **Premiere Pro 用スクリプト** です。ご自身のMacのPremiere上で実行します。

> **なぜスクリプトなのか**
> この作業はクラウド環境で行いました。そこには Premiere 本体も元動画（.MOV）もありません。そのため `.prproj` を直接書き換えて渡す方法は検証できず、壊れたプロジェクトを渡す危険がありました。
> そこで、素材があるご自身のPremiere上で、公式スクリプトAPIを使って編集する方式にしています。

## フォルダ構成

| パス | 内容 |
|---|---|
| `dist/episode19_auto_edit.jsx` | **実行するスクリプト**（これだけをPremiereで実行） |
| `episode19_plan.jsxinc` | 時刻・文言・配置の定義（単一の情報源） |
| `docs/タイムライン計画.md` | 完成タイムコード付きの配置計画（自動生成） |
| `docs/素材と未対応項目.md` | 使用素材・不足素材・自動配置できない項目、前回プロジェクトの解析結果 |
| `src/episode19_auto_edit.src.jsx` | スクリプトのソース（日本語コメント付き） |
| `tools/build.py` | ソースと計画から `dist/` と `docs/タイムライン計画.md` を生成 |
| `tools/mock_premiere_test.js` | Premiere APIのモックで動作を確かめる試験ツール |

## 1. 準備（約5分）

作業フォルダ（元の `.prproj` があるフォルダ）を、次の構成にしてください。

```
19_…/02_プロマネ/コピー_覚醒体験した人、ディセンション恐れすぎ問題/
├─ 覚醒体験した人、ディセンション恐れすぎ問題.prproj      ← 元プロジェクト（変更されません）
├─ 二極化の時代へ！覚醒する人が手放した5つのもの_修正 1.prproj ← 前回プロジェクト（ここに無ければ実行時に選択）
└─ episode19_assets/
   ├─ 01_経済的不安.png … 06_不安が戻る.png
   ├─ 素材配置一覧.csv
   └─ templates/
      ├─ title.mogrt      ← ハイライトタイトル用
      ├─ emphasis.mogrt   ← 強調テロップ用（左揃え）
      └─ diagram.mogrt    ← 図解文字用（中央揃え・画面中央）
```

### テンプレート（.mogrt）の書き出し

前回デザインのフォント・サイズ・影・色・余白は、前回のハイライトタイトル（YuMin-Medium のポイントテキスト）から引き継ぎます。Premiereのスクリプトでは新しいテキストレイヤーを作れないため、このテンプレートが必要です。

1. 前回プロジェクトを開き、シーケンス「10_二極化の時代へ！覚醒する人が手放した5つのもの」を開く。
2. V4 の 00:00 にあるタイトルクリップ（「セレン愛が紐解く／「覚醒」の本質」）を選択する。
3. メニュー **グラフィックとタイトル > モーショングラフィックステンプレートとして書き出し** を選ぶ。保存先は「ローカルドライブ」→ `episode19_assets/templates`、名前は `title` にする。
4. 同じクリップを Option キーを押しながらドラッグして複製する。エッセンシャルグラフィックスで **左揃え** にして、`emphasis` の名前で書き出す。
5. もう一度複製し、**中央揃え**・文字サイズ約60%・整列で **画面の水平・垂直中央** に置き、`diagram` の名前で書き出す。
6. 前回プロジェクトは **保存せずに閉じる**（元シーケンスを変更しないため）。

テンプレートが無い項目は、スクリプトが代わりのものを作らずに赤マーカーを置きます。

## 2. 実行

1. 元プロジェクト「覚醒体験した人、ディセンション恐れすぎ問題.prproj」を開く。
2. `dist/episode19_auto_edit.jsx` を実行する。
   - **VS Code + Adobe「ExtendScript Debugger」拡張**で、ターゲットに Premiere Pro を選んで実行（推奨）。
   - スクリプトランチャー系のパネルを入れている場合は、そこからでも実行できます。
3. 確認ダイアログで「はい」を選ぶ。処理の流れは次のとおりです。
   1. **元プロジェクトを変更せず**、`…_自動編集案_v1.prproj` として別名保存する。
   2. 元シーケンスを複製して「**19_ディセンション恐れすぎ問題_自動編集案_v1**」を作る。
   3. 以降の編集は、この複製シーケンスにだけ行う。
4. 完了すると、プロジェクトと同じフォルダに次の2つができます。
   - `19_ディセンション恐れすぎ問題_自動編集案_v1_レポート.md`（使用素材・不足素材・未処理項目・自動チェック結果）
   - `19_ディセンション恐れすぎ問題_自動編集案_v1_確認用TC.mp4`（タイムコード入り確認用）

## 3. 自動で行うこと

| 項目 | 内容 |
|---|---|
| 構成 | ハイライト①②③ → オープニング① → オープニングトーク → オープニング② → 本編。全尺は **06:45:11**。詳細は `docs/タイムライン計画.md` を参照 |
| ハイライト | 複製シーケンスから3区間をサブシーケンスとして複製し、本編側からは削除しない。前回デザインと同じく基本テロップを外し、話者110%＋タイトルにする。つなぎ映像・SEは入れず、4フレームの短いフェードだけでつなぐ |
| オープニング①② | 前回プロジェクトを**読み込んだコピー**から、前回00:16.17〜00:21.20と01:03.60〜01:10.47をサブシーケンス化する（前回ファイルは変更しない） |
| BGM | 前回と同じ「全ては一つ日本語 (1).m4a」を前回の音量で、00:00:00〜オープニングトーク終了まで。オープニング②は前回のBGMをそのまま使う |
| CSVマーカー | `素材配置一覧.csv` の14行を、挿入**前**の時刻でマーカー化してから、クリップと一緒に移動する |
| 肩書修正 | 「神聖覚醒起動者」→「神性覚醒起動者」（複製側の1か所だけ）。この版のPremiereで書き換えられない場合は赤マーカーを置く |
| 強調テロップ・タイトル | 設計書の7件＋「最大強調」1件＋ハイライトタイトル3件を、前回デザインのMOGRTでV8に置く（ポイントテキスト、2行は左揃え） |
| 写真 | `episode19_assets` の01〜06をローカルから直接読み込む。文頭から文末まで表示し、画面いっぱいの拡大率から静かにプッシュする（100→103%、05は101→105%、06は100→102%） |
| 図解文字 | A〜D の文字をセリフに合わせて段階表示する（V4〜V7、項目ごとに別トラック） |
| 画角 | 設計書の6区間（108/110%）をカット点で切り替える。03:55.03と05:31.80は元のカット点がないため、V1を同じショット内で分割する（内容・尺は変わらない） |
| 色 | 話者クリップにLumetriカラーを、設計書の開始目安値で適用する（後から変更可能） |
| 確認 | V1の空き（黒画面）・A1の空き（無音）・オフライン素材・全尺・構成順を自動チェックし、確認用シーケンスにタイムコードを入れてMP4を書き出す |

## 4. 手作業が必要な項目

詳しくは `docs/素材と未対応項目.md` を参照してください。

- **図解A〜Dのシェイプ・矢印・円**：PremiereのスクリプトAPIではシェイプを作れません。橙マーカーに作り方を書いてあります。
- **色の最終調整**：前回プロジェクトにはLumetriや色補正の調整レイヤーがなく、参照する数値がありません。開始目安値から、波形・ベクトルスコープで顔・白ジャケット・窓側のハイライトを見て調整してください。
- **00:37.80〜01:01.53 の「要点だけ軽く強調」**：強調する語が指定されていないため、自動では入れていません（白マーカー）。
- **図解Cと強調テロップ「高い次元も 低い次元も／愛である」が同時に出る区間**：レイアウトの干渉を確認してください（白マーカー）。
- **全編の目視確認**：音声の切れ、テロップのはみ出し、インサートの文頭・文末、オープニングの順番を確認用MP4で見てください。

## 5. うまく動かないとき

- **「トラックを追加できませんでした（QE DOM 無効）」**：編集は行わずに中止しています。作業用 `…_自動編集案_v1.prproj` を削除し、Premiereを再起動してから再実行してください。
- **二重実行の防止**：作業用プロジェクトか「…_自動編集案_v1」シーケンスが既にあると、スクリプトは中止します。やり直すときは作業用 `.prproj` を削除してください。元プロジェクトはそのまま残っています。
- **ExtendScriptが使えない版**：Adobe は ExtendScript から UXP への移行を進めています。お使いの版でExtendScriptを実行できない場合はご連絡ください。
- **MP4にタイムコードが入らなかった場合**：確認用シーケンスを書き出してから、次のコマンドで焼き込めます。

```bash
ffmpeg -i in.mp4 -vf "drawtext=fontfile=/System/Library/Fonts/Supplemental/Arial.ttf:timecode='00\:00\:00\:00':rate=30:fontsize=44:fontcolor=white:box=1:boxcolor=black@0.5:x=40:y=40" -c:a copy out_TC.mp4
```

## 開発者向け

```bash
python3 premiere/episode19/tools/build.py
```

```bash
node premiere/episode19/tools/mock_premiere_test.js cur.json prev.json <作業フォルダ> [--no-qe]
```

モック試験の確認範囲は、スクリプト自身のロジック（順番・時刻計算・未処理時のマーカー化・レポート）だけです。実際のPremiere APIの挙動は、実機で確認してください。
