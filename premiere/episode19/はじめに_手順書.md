# 19 自動編集 — はじめての方向け手順書

スクリプトやVS Codeの知識は不要です。Premiere Pro の中に「19 自動編集」というパネル（ボタンが2つある小さな画面）を追加し、ボタンを押して使います。

**安全のための約束**

- 元のプロジェクトは開きません。Finderで作った「確認用」のコピーだけを使います。
- スクリプトは、名前に「確認用」が付いていないプロジェクトでは何もせずに止まります。
- 実行時には、確認用プロジェクトをさらに別名（…_確認用_自動編集案_v1.prproj）で保存してから作業します。
- 基本テロップは変更しません。肩書「神聖→神性」の修正も行いません（最後に手作業で行う前提）。

---

## 手順1　キットを展開する

1. ダウンロードした `episode19_premiere_kit.zip` を Finder の「ダウンロード」フォルダで探す。
2. ダブルクリックする。同じ場所に `episode19_premiere_kit` フォルダができる。

完成後の場所（通常）: `/Users/az/Downloads/episode19_premiere_kit/`

## 手順2　パネルを Premiere に追加する（1回だけ）

1. Premiere Pro を開いていれば終了する（メニュー「Premiere Pro」>「Premiere Pro を終了」）。
2. キーボードで **⌘（command）+ スペース** を押し、「ターミナル」と入力して **return** を押す。
3. 開いた黒（または白）のウィンドウに、次の1行をコピーして貼り付け（⌘+V）、**return** を押す。

```bash
bash ~/Downloads/episode19_premiere_kit/install_panel.command
```

4. 「完了しました。」と表示されたら、ターミナルを閉じる（⌘+Q）。

この操作では、パネルのコピーと、パネル読み込みの許可設定だけを行います。動画やプロジェクトには触れません。

## 手順3　確認用プロジェクトを作る（元は開かない）

1. Finder で、元プロジェクトのあるフォルダを開く（動画素材 .MOV と同じフォルダの場合、次の場所です）。
   `/Users/az/Downloads/セレン 愛 様/19_覚醒体験した人、ディセンション恐れすぎ問題/02_プロマネ/コピー_覚醒体験した人、ディセンション恐れすぎ問題/`
2. 「覚醒体験した人、ディセンション恐れすぎ問題.prproj」を **右クリック** >「**複製**」を選ぶ。「…のコピー.prproj」ができる。
3. できたファイルをクリックして **return** を押し、名前を次のように変えて return を押す。
   `覚醒体験した人、ディセンション恐れすぎ問題_確認用.prproj`
4. 同じフォルダに `episode19_assets` フォルダがあることを確認する（写真 01〜06 と素材配置一覧.csv が入ったもの）。
5. 前回プロジェクト「二極化の時代へ！覚醒する人が手放した5つのもの_修正 1.prproj」を、**option キーを押しながら**このフォルダへドラッグしてコピーする。
   - 移動ではなくコピーされます。カーソルに「＋」が付いていればコピーです。

## 手順4　確認用プロジェクトを開いて「確認」を押す

1. 手順3で作った「…_確認用.prproj」をダブルクリックして Premiere で開く。
   - メディアのリンク確認画面が出た場合は、元プロジェクトと同じ対応をしてください。
2. Premiere のメニュー「**ウィンドウ**」>「**エクステンション**」>「**19 自動編集**」を選ぶ。
3. 出てきたパネルの「**① 確認する（何も変更しません）**」を押す。
4. ○×の一覧が出る。すべて ○ なら手順5へ進む。× があれば、その内容を知らせてください。

## 手順5　「実行」を押す

1. パネルの「**② 自動編集を実行する**」を押す。
2. 確認ダイアログで「**はい**」を押す。数分かかります。
3. 「完了しました」と出たら、プロジェクトパネルの「シーケンス」ビンにある「**19_ディセンション恐れすぎ問題_自動編集案_v1**」をダブルクリックして開く。
4. 同じフォルダに次の2つができています。
   - `19_ディセンション恐れすぎ問題_自動編集案_v1_レポート.md`：テキストエディットで開ける
   - `…_確認用TC.mp4`：タイムコード入りの確認用動画

## 手順6　結果を確認する

- 確認用MP4で全編を再生し、次の点を見てください。
  - 音声の切れ
  - 黒画面
  - テロップのはみ出し
  - 写真の出始めと終わり（文頭・文末）
  - オープニングの順番
- タイムラインの **赤・橙・白・紫のマーカー** は手作業か確認が必要な場所です。内容はレポートにまとまっています。
- 肩書「神聖→神性」は、確認がすべて終わってから手作業で修正してください。

## テキストを自動で作れなかったとき（.mogrt の書き出し）

スクリプトはまず、前回プロジェクトのタイトル（YuMin-Medium のポイントテキスト）を自動で複製し、文字だけを差し替えます。

お使いのPremiereがこの差し替えに対応していない場合は、レポートに「前回タイトルの文字差し替えは、このPremiereでは使えませんでした」と出て、テキストの場所に赤マーカーが置かれます。その場合だけ、以下の手順でテンプレートを3つ書き出してから、もう一度試します（手順3〜5をやり直し）。

1. Finder で前回プロジェクトのコピーを作る。
   - 「二極化の時代へ！…_修正 1.prproj」を右クリック >「複製」。
   - 名前を「…_テンプレ書き出し用.prproj」にする。
2. そのコピーをダブルクリックして Premiere で開く。
3. 左下の「**プロジェクト**」パネルで、シーケンス「**10_二極化の時代へ！覚醒する人が手放した5つのもの**」をダブルクリックする。
   - 同じ名前が2つある場合は、ビン「シーケンス」にある方を使う。
4. 右下の「**タイムライン**」パネルで、上から4本目の映像トラック **V4** の先頭（00:00:00:00）にあるクリップをクリックして選ぶ。
   - タイトル「セレン愛が紐解く／「覚醒」の本質」のクリップです。
5. 画面上部のメニュー「**グラフィックとタイトル**」>「**モーショングラフィックステンプレートとして書き出し…**」を選ぶ。
6. 開いた画面で、次のように設定して「**OK**」を押す。
   - 名前：`title`
   - 書き出し先：「**ローカルドライブ**」を選んで「**参照…**」を押し、確認用フォルダの `episode19_assets` の中に `templates` フォルダを作って選ぶ（「新規フォルダ」ボタン）。
7. 同じクリップを選んだまま、メニュー「**ウィンドウ**」>「**プロパティ**」を開く。
   - 古い版では「ウィンドウ」>「エッセンシャルグラフィックス」の「**編集**」タブです。
8. テキストの揃え方のボタンで「**左揃え**」を押す。手順5〜6を繰り返し、名前を `emphasis` にして書き出す。
9. 次の設定に変えてから、手順5〜6を繰り返し、名前を `diagram` にして書き出す。
   - 揃え方：「**中央揃え**」
   - 整列：「**垂直方向に中央揃え**」と「**水平方向に中央揃え**」で画面中央に置く
   - フォントサイズ：今の6割くらい
10. メニュー「ファイル」>「プロジェクトを閉じる」を選び、「**保存しない**」を押す。

## パネルが表示されないとき

- 手順2のあと、Premiere を完全に終了してから開き直したか確認してください。
- それでも「エクステンション」にない場合は、お使いのPremiereがこの形式のパネル（CEP）に対応していない可能性があります。お知らせください。
